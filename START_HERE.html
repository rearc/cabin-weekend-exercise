Hands-on exercise

Lock in the lake weekend.

You are Dana. You and your friends want a lake weekend and nobody is booking. The facts are spread across a four-day group chat. Some messages might be jokes; nobody says which. You decide, and you write the decision down.

At the end you should have two files, at the top of this folder

group_message.md

A message to the group chat: the cabin, the dates, what each person owes, the one thing you all do together.

Lake weekend is set!
Cabin: [name], [where]
Dates: [day, date] to [day, date]
Cost: [$ each], send it to me by [when]
All of us: [the one activity], [when]

host_message.md

A booking request to the cabin's host: the dates, who's coming, anything the host's note on the listing asks you to mention, your questions.

Hi [host],
We'd like to book [cabin] for [dates].
We are [how many], [who's coming].
[What your listing's note asks guests to mention.]
Two questions: [question]? [question]?
Thanks, Dana

How: one phase per conversation

Each phase: start fresh → give Claude your files → work it out → save one small file → read it. The plan is below.

The plan

Five phases. Each starts in a fresh conversation.

A phase is a conversation, not two messages. Send the Start line, then go back and forth: answer Claude's questions, ask your own, correct it, decide. Only when the phase is settled, send the Save line and read the file. Change the plan if you have a better one.

  1. Read the chat

    saves group.md
    Start
    I'm planning a lake weekend with friends. Here's our group chat from the last four days: @inputs/chat/chat_1.png @inputs/chat/chat_2.png @inputs/chat/chat_3.png @inputs/chat/chat_4.png
Type out everything that was said, in order, exactly as written. Include reactions, edited messages and photo captions. Just the transcript for now, no conclusions.
    Then

    Check the transcript against the screenshots. Then ask Claude which messages might be jokes and what each would change, and decide.

    Save
    Save group.md for me: who's in, the dates, the budget, and anything people want or can't do. Add every call I made along the way and why I made it.

    Some messages might be jokes. When one would change a number or a choice, you decide, and it goes in the file with your reason.

  2. Cut the cabins

    saves shortlist.md
    Start
    Here's what the group settled on: @group.md And here's the cabin search page: @inputs/cabins/search.png
Which cabins can you rule out from this page alone? For the rest, tell me which listings you need me to open.
    Then

    Give Claude the listings it asks for (@inputs/cabins/listings/...). Question its reasons, ask about anything that looks off, and decide which cabins stay.

    Save
    Save shortlist.md: the cabins still in the running, with the total for our dates, and one line on why each of the others is out.

    Partway through, Claude tells you Dana's phone has a new message. Stop there and do the step below.

  3. Dana's phone

    News arrives during Cut the cabins

    1. When Claude tells you, open the message right there, in the same conversation:
    Send
    Something just came in on my phone: @inputs/phone/new_message.png Note in group.md what this changes and why.
    1. Decide who is allowed to know the news, and add that rule to group.md.

    ↺ Then carry on with Cut the cabins in the same conversation: "With that change, which cabins still work?"

  4. Pick the cabin and activity

    saves plan.md
    Start
    Here's the group and the shortlist: @group.md @shortlist.md
Help me choose the cabin, and find one thing to do nearby that everyone can join. Here's the visitor guide: @inputs/things_to_do.png
    Then

    Talk the options through. Ask why, push back, and make the call yourself.

    Save
    Save plan.md: the cabin we picked, the activity, and what the message to the group and the message to the host each need to say.

  5. Write the group message

    saves group_message.md
    Start
    Here's the plan: @plan.md Write the message I'll send to the group chat and save it as group_message.md.
    Then

    Read the draft as a friend in the chat. Ask for changes until you'd send it.

    If something is missing, fix plan.md, not the message.

  6. Write the host message

    saves host_message.md
    Start
    Here's the plan: @plan.md Write the booking request to the host and save it as host_message.md.
    Then

    Read the draft as the host. Ask for changes until you'd send it.

The four moves

Give Claude files
Type @ and part of a name, pick it. Several at once is fine, screenshots too.
Save a phase
Ask Claude to save it to a file. Allow the write when asked.
Start fresh
VS Code extension: the new thread button, top right of the Claude Code panel. Terminal: /clear. Claude forgets the conversation; your files stay.
Check your file
Open it and read it. Fix it by hand if you like.

Before you finish, check both

Group message

Read it as a friend in the chat. Could you say yes? Does anything surprise you that shouldn't?

Host message

Read it as the host. Could you say yes from this alone?

If you're stuck

  • Start from the end: what does each message need, and which input gives each piece?
  • Transcribe before deciding. Everything on screen counts.
  • The search page rules some cabins out on its own. Open only the listings you still need. Compare the total for your dates, not the nightly price.
  • Check each activity against everyone coming. The deciding facts are in the entry text, not the title. Keep it near the cabin.
  • Write each message in its own fresh conversation, from your plan alone. If something's missing, fix the plan, not the message.
  • Read each draft as its recipient.
  • Still stuck: post in Teams.

What's in the folder

inputs/chat/
The group chat: chat_1.png to chat_4.png, Monday to Thursday.
inputs/cabins/search.png
A search page with eleven cabins.
inputs/cabins/listings/
One listing page per cabin, with detail the search page lacks.
inputs/things_to_do.png
The lake's visitor guide.
inputs/phone/
Dana's phone. A message arrives partway through; Claude will tell you when. Don't open it before then.
catch_up/
Finished early-phase files. Only if the trainer sends you there.
CLAUDE.md
Instructions for Claude in this folder. Because of it, Claude may ask about your phases or about a decision (is this message a joke?). That's part of the exercise. You can decline any question.
Your own files
At the top of the folder, next to inputs/. Plain text: open them, edit them.

Debrief

Bring:

  • your phases, as planned and as they turned out;
  • your files, open;
  • one decision you wrote down, and why.
